# P2 relocation experiment: negative checkpoint

## Result

Two relocation schedules were tested with paired memory-disabled and memory-enabled P2 founders. Both schedules caused extinction in every seed by tick 20,000.

The revised schedule placed founders at the first oasis and moved all food/water sources between two oases every 400 ticks (20 simulated seconds). Even then, the population could not maintain a viable reproductive ecology after repeated map-wide moves.

## Interpretation

This is not evidence that cognition is biologically useless. It is evidence that the present relocation scenario is invalid for measuring cognition: it imposes synchronized, long-range resource loss on every creature. It should not be used to tune memory genes or score a P2 success/failure gate.

## Next P2 design requirement

Replace global source teleportation with a spatially local, partially predictable resource-pattern experiment. Some sources must remain available while others rotate, so remembered knowledge can create an advantage without turning each transition into an extinction event. The experiment must include a stable control and retain the same cognition maintenance costs.
